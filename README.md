# StudyHub

StudyHub is a multi-page student website developed for **Web Engineering Assignment 01**.

## Assignment

**Course:** Web Engineering  
**Program:** BSCS  
**Semester:** 5  
**University:** University of Lahore  
**Assignment:** Web Page Development using HTML, CSS and Tailwind CSS

## Pages

- Home
- About
- Contact
- Sign Up
- Sign In

## Technologies

- HTML
- CSS
- Tailwind CSS
- Flowbite
- Formspree

## Features

- Responsive navigation
- Hero section
- Tailwind CSS components
- Contact form with Formspree
- Sign Up and Sign In pages
- Responsive design
